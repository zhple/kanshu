# 看书（Kanshu）

本地 Android 电子书阅读 App：导入 TXT / EPUB / PDF、文件夹分类、按屏分页滑动翻页、白天/黑夜模式，支持检查 GitHub Release 自动更新。

## APK

- 本机：`release/kanshu-v1.2.0.apk`
- Release：https://github.com/zhple/kanshu/releases

## 使用

1. 右下角 **+** 导入 `.txt` / `.epub` / `.pdf`
2. 顶栏文件夹图标可新建分类；点文件夹进入；书籍菜单可移动/删除
3. 阅读页左右滑动翻页；点中间显隐工具栏
4. 书架右上角可检查更新

## 发布更新

提高 `versionCode`，打 Tag（如 `v3`），把 APK 上传到 GitHub Release。
